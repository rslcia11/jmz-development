the site's tokens (Geist, `#f5f3ee` on `#0b0b0a`, amber `#d6a56b` core).
Preview: [propuestas.png](propuestas.png).

| | File | Idea |
| --- | --- | --- |
| A · Sistema | `a-sistema.svg` | The site's six-module system as symbol, plus the wordmark. |
| B · Core | `b-core.svg` | Wordmark only; JMZ ends in the lit core. |
| C · Bloques | `c-bloques.svg` | Letters built from modules; the core is the M's middle stroke. |

Not final: the wordmarks still use live Geist text; the chosen one gets its
letters outlined to paths before it ships.
